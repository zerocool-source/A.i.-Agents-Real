# ListingDesk — design brief

**Product.** One real estate agent's personal command desk (Leslie Smith,
Keller Williams The Lakes, Southern California). Stage listings, generate
vertical-video walkthrough scripts instantly, work leads, and run the whole
marketing engine (social, email, ads, team, payments) from one page.

**Concept spine: the premium open-house flyer.** The desk looks like the
marketing it produces: warm ivory stock, a deep wine brush band, gold
accents, serif headlines, and a handwritten greeting. Confident, personal,
print-inspired. The user supplied the reference: her own "Did You Know"
farming flyer (wine brush swash, cream paper, gold house icons, script
"Hi, I'm", serif name, checkmark fact list).

## System: "Sunday Flyer"

- **Palette (locked):** ivory stock `#F7F1E6`, panel `#EFE7D6`, card
  `#FCF9F1`, ink `#241C18`, hairline `#DDD2BC`, and a two-tone accent straight
  off the flyer: wine `#7C2130` (deep `#571622`) for identity and primary
  actions, gold `#B8862E` (soft `#E6CF9A`) for hairlines, seals, and warmth.
- **Type:** Fraunces (serif display: headlines, prices, panel titles),
  Public Sans (body/UI), Spline Sans Mono (data, labels, uppercase micro
  labels), Great Vibes (script, used exactly twice: hero greeting + agent
  card). All self-hosted woff2.
- **Corners:** 14px cards, with the agent card slightly rotated and
  organically-rounded (brush-tilted) as the one expressive shape.
- **Brand mark:** gold roofline chevron with a chimney notch on a wine tile
  (favicon, nav, integrations plate, OG card).
- **Imagery:** none generated. The identity is typographic + brush shapes
  (zero-credit build); the OG card is composed locally (ivory stock, ragged
  wine band, script greeting).
- **Signature moves:** the tilted wine agent card in the hero (her flyer
  contact block); the gold "payband" banner (the flyer's FREE report bar);
  the wine wire-log rail; diamond-stud stage meters.
- **Bespoke CTA garments (no shared button style):**
  - Generate walkthrough = wine record-pill whose gold lens blinks like a
    camera tally light on hover.
  - Run task = round gold seal ring that stamps solid on hover.
  - Payband = solid gold banner.
  - Send = cream chip that stretches its tracking.
  - New task/listing = dashed gold tray with rotating plus.
  - Connect = physical flip switch, wine when on.
  - Advance = mono text link that widens its tracking.
- **Copy rules:** no em-dashes in visible copy, headlines 8 words max,
  second person to Leslie, plain functional copy.
- Mobile: single column, agent card untilts, nav subtitle hidden.

## Anti-convergence ledger (vs the two prior builds this session)

| Axis | AgentForge "Drafting Room" | SunDesk "First Light" | ListingDesk "Sunday Flyer" |
|---|---|---|---|
| Palette | chalk + cobalt | morning glass + ember | ivory + wine + gold (two-tone) |
| Display type | Satoshi (sans) | Outfit (sans) | Fraunces (serif) + script |
| Hero | split w/ parallax instrument photo | full-bleed rooftop photo | typographic flyer band + tilted card, no photo |
| Corners | 10px soft | 6px crisp | 14px + organic brush shapes |
| Primary CTA garment | cobalt corner brackets | ember sunrise chip | wine record-pill w/ tally lens |
| Dark rail | deep cobalt | deep pine | deep wine |
| Data font | JetBrains Mono | IBM Plex Mono | Spline Sans Mono |

Differs on all seven axes (requirement: at least four).
